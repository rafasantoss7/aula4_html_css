Guia CSS

Seletor de atributo

Utilização: seleciona elementos que possuem determinado atributo HTML ou um atributo com um valor específico. É útil para personalizar campos de formulário e links.

Exemplo de uso:

/* Seleciona campos que possuem o atributo required */
input[required] {
border: 2px solid red;
}
/* Seleciona links que abrem em nova aba */
a[target="_blank"] {
color: purple;}


Resultado: campos obrigatórios terão borda vermelha e links com target="_blank" terão texto roxo.

Seletor descendente

Utilização: seleciona elementos que estão dentro de outro elemento, em qualquer nível da hierarquia, não apenas como filhos diretos.

Exemplo de uso:

Head:

article p {
color: #176b45;
}

Body:

<article>
  <p>Este parágrafo será verde.</p>
  <div>
    <p>Este também será verde.</p>
  </div>
</article>

Resultado: todos os parágrafos dentro de article serão verdes, inclusive os que estiverem dentro de outros elementos.

Seletor filho direto

Utilização: seleciona somente os elementos que são filhos imediatos de outro elemento. Não inclui elementos que estejam em níveis mais profundos.

Exemplo de uso:

Head:

section > p {
font-weight: bold;
}

Body:

<section>
  <p>Este parágrafo ficará em negrito.</p>
  <div>
    <p>Este não será selecionado por essa regra.</p>
  </div>
</section>

Resultado: apenas o primeiro parágrafo será selecionado, pois é filho direto de section.

Seletor adjacente direto

Utilização: seleciona o elemento B quando ele aparece imediatamente depois do elemento A e ambos possuem o mesmo elemento pai.

Exemplo de uso:

Head:

h2 + p {
color: #b45309;
}

Body:

<h2>Título</h2>
<p>Este parágrafo será selecionado.</p>
<p>Este não será selecionado por essa regra.</p>

Resultado: somente o primeiro parágrafo após o título terá a cor indicada.

Seletor de irmãos gerais

Utilização: eleciona todos os elementos B que aparecem depois de A e compartilham o mesmo elemento pai. Diferentemente do seletor adjacente, não precisam estar imediatamente um após o outro.

Exemplo de uso:

Head:

h2 + p {
background-color: #fff0c2;

Body:

<div>
  <h2>Título</h2>
  <p>Este será selecionado.</p>
  <span>Elemento intermediário</span>
  <p>Este também será selecionado.</p>
</div>
}


Resultado: os dois parágrafos posteriores ao título terão fundo amarelo-claro.

Seletor de pseudoclasse

Utilização: aplica estilos quando um elemento está em determinado estado ou ocupa uma posição específica. Pseudoclasses são escritas com dois-pontos, como :hover, :focus e :first-child.

Exemplo de uso:

button:hover {
background-color: #173b67;
color: white;
}
input:focus {
outline: 2px solid #7048a8;
}

Seletor de pseudoelemento

Utilização: stiliza uma parte específica de um elemento ou cria um detalhe visual sem precisar adicionar outro elemento ao HTML. A forma moderna usa dois-pontos duplos.

Exemplo de uso:

Head:

p::first-letter {
font-size: 2em;
color: #7048a8;
font-weight: bold;
}
.destaque::before {
content: "★ ";
color: #b45309;
}

Body:

<p>Este parágrafo terá a primeira letra destacada.</p>
<p class="destaque">Este texto terá uma estrela antes.</p>

Resultado: a primeira letra do parágrafo fica maior e roxa; no segundo exemplo, uma estrela aparece antes do texto.
